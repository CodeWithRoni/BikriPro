BikriPro Brand Asset Package
============================

Selected concept: Ocean Blue (Dark + Light)

Main assets
-----------
BikriPro_Logo.png
BikriPro_App_Icon.png
BikriPro_Windows.ico

Platform-ready icon assets
--------------------------
Windows: ICO + PNG sizes
macOS: iconset PNGs ready to run through macOS `iconutil`
Android: mipmap density folders
iOS: common AppIcon PNG sizes
Linux: common desktop PNG sizes

Important
---------
This ZIP contains the selected BRANDING/ICON ASSETS.

It does NOT contain actual application installers:
.exe, .dmg, .apk, .ipa, or .deb.
Those are compiled application packages and require the finished
BikriPro source code/build configuration. The selected logo and icon
can be integrated into all of those builds.
